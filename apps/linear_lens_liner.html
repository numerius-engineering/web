Help — Linear Lens Liner

The basics

  • Add a component: click Add Source, Add Lens, or Add Sink, then click the canvas to place it.
  • Select / move: in Select mode, click to select, drag to move (snapped to the current grid size).
  • Edit properties: double-click a component. Numeric fields are "roller" controls — drag left/right, scroll over them, use the +/- buttons, or click once to type a value directly. A shared step size at the bottom of the panel sets the roller increment; "Recompute on change" controls whether edits re-run the ray-trace live or only on Save.
  • Keyboard: Delete removes the selection, arrow keys nudge it by one snap step, Ctrl+D duplicates it, Ctrl+S downloads the design as JSON, Ctrl+O loads one.
  • Canvas: scroll to zoom, middle-mouse-drag to pan, Fit View to frame the whole design.

Ray tracing — "Compute Rays"

Traces every source's rays (evenly spaced across its beam width, up to 99 per source) through all lenses to every downstream sink. Results — spot diameter, centroid, magnification, angular magnification, a per-ray table, and a clipping report — appear in the side panel. Rays that miss a component's clear aperture are clipped. Ray Colors in the toolbar switches between grayscale shading and a ROYGBV spectrum across the ray bundle.

Lens geometry tools

Every lens's property panel includes an Index of refraction field (with a calculator for n = √εr from relative permittivity), a Geometry Report button (downloads a tabulated .txt of derived surface radii/sag/edge thickness), and a Generate in FreeCAD button (downloads a .FCMacro Python macro that builds the lens as a real solid body). Idealized "Thin" lenses have no physical surfaces to report or model; meniscus shapes assume a documented radius ratio, since focal length and index alone can't uniquely fix two radii.

Fourier optics — "Compute Fourier"

Opens a wave-optics configuration panel: choose a Source/Sink pair, a source amplitude function (Gaussian/boxcar/triangular — pointing and divergence become an exact tilt and wavefront curvature), wavelength, FFT size, box clipping height (the Auto button sets it to 2× the tallest component), and propagation step size in µm (keep this well below a lens's surface sag to resolve its curvature accurately). Physical lenses are meshed directly into the propagation grid using their real refractive index; idealized Thin lenses fall back to a phase-screen approximation. A progress bar shows an estimated time remaining, and Cancel stops a run in progress. When finished, download results.json (complex field at both planes) and view four plots: source/sink × amplitude/unwrapped phase.

Global media index

The Media Index control in the toolbar is used everywhere: it adjusts each lens's effective focal length in the ray-trace (a lens in water is weaker than the same lens in air) and sets the background index for the Fourier calculation, so both stay consistent.

Saving and loading

Save downloads the current design (components, snap size, zoom) as JSON. Load reads one back in.
