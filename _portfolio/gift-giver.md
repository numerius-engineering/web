  <h1>Gift Giver</h1>
  <p class="lead">Gift Giver is a small, festive browser app that turns a list of names into a Secret Santa exchange, delivered as a single self-contained HTML file.</p>
</section>

<section class="section-grid">
  <article class="content-block">
    <h2>Project focus</h2>
    <p>Participants are entered one per line or as a comma-separated list. The app shuffles them into a single random cycle, so everyone gives exactly one gift and receives exactly one, and nobody draws themselves.</p>
    <p><a href="{{ '/apps/gift_giver.html' | relative_url }}">Launch the live browser app</a></p>
  </article>
  <article class="content-block">
    <h2>What it demonstrates</h2>
    <p>Gift Giver shows how a polished, themed user experience can fit in a tiny dependency-free package: unbiased cryptographic shuffling, input validation, animated reveal, clipboard export, accessibility cues, and a responsive layout.</p>
